## 🚀 Featured Projects

### 📄 [Document Portal](https://github.com/madhugadi/Document_Portal)
An intelligent document platform where you can upload PDFs, analyze them, compare documents side by side, and chat with them. Answers are grounded in the documents using RAG with a FAISS vector store.
- Async FastAPI backend with structured logging and custom error handling
- Containerized and deployed on **AWS ECS Fargate** behind a load balancer, with secrets in AWS Secrets Manager
- CI/CD with GitHub Actions and a Streamlit front end

`Python` `FastAPI` `RAG` `FAISS` `Docker` `AWS ECS` `GitHub Actions`

### 🛒 [E-Commerce Product Assistant](https://github.com/madhugadi/ecomm-prod-assistant)
An AI shopping assistant that answers natural-language product questions using hybrid retrieval.
- Semantic search with embeddings and reranking, plus contextual compression to cut token use and hallucinations
- Falls back to live web search when the product data doesn't have the answer
- Modular MCP-based design (retrieval, ranking, compression, generation) running as microservices on **AWS EKS**

`LangChain` `LangGraph` `MCP` `Astra DB` `Kubernetes` `AWS EKS`

### 📑 [Automated Research Report Generator](https://github.com/madhugadi/automated-research-report-generation)
A multi-agent system that researches a topic and writes a full report. It creates a team of AI "analyst" personas, gathers sources from the web and Wikipedia, takes human feedback along the way, and assembles an introduction, findings, and conclusion, then exports the result as **Word or PDF**.

`LangGraph` `Multi-Agent` `Tavily` `FastAPI` `Human-in-the-loop`

### 📰 [PublicPulse](https://github.com/madhugadi/publicpulse)
An editorial intelligence platform that explains how audiences are reacting right now to new movies and gadgets, based on early public comments. Rather than ratings or hype, it gives calm, balanced summaries of what's working, what's mixed, and emerging concerns, and it updates as new reactions arrive.

`FastAPI` `YouTube Data API` `Groq` `Next.js 14` `TypeScript` `Tailwind`

### 💊 [Fine-Tuning LLMs on AWS](https://github.com/madhugadi/Fine-tuning-onAWS)
Fine-tuning a small open-source language model (TinyLlama) on a pharmaceutical question-and-answer dataset using **LoRA**, with training jobs run and deployed through **Amazon SageMaker**.

`Hugging Face` `PEFT / LoRA` `Amazon SageMaker` `PyTorch`

### 🧩 [Building an LLM from Scratch](https://github.com/madhugadi/Building_LLM_from_Scratch)
Learning how language models work from the ground up, starting with a character-level bigram model trained on *The Wizard of Oz* and building toward a GPT-style model.

`PyTorch` `Transformers` `NLP`
